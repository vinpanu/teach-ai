Idea 02 · Skills

          
Stop re‑explaining.
Teach it once.

          
A skill is a saved playbook. Your AI pulls it out whenever the task comes up.

        

        

          

            
Week 1Status report, please. Use our format: Done, Next, Risks. One page. Flag anything late.

            
Week 2Status report again. Remember: Done, Next, Risks. One page. Flag anything late.

            
Week 3 😩Same as last week! Done, Next, Risks. ONE page. Flag anything late!

          

          

          
📄SKILL.mdweekly-status-report

          

            
Status report, please. Notes attached.

            
✓ Done, in your team's format.

          

          

        

      

    


    
    

      

        
What's inside a skill

        
A folder and one text file.

        

          

            
weekly-status-report / SKILL.md

            

              

                
---

                
name: weekly-status-report

                
description: Turns rough project notes into our team's weekly status report. Use when someone asks for a status report, weekly update or project summary.

                
---

              

              

                
# Weekly status report

                
1. Group the notes by project.

                
2. For each project: ✅ Done · 🔜 Next · ⚠️ Risks.

                
3. Mark anything late or over budget as ⚠️ At risk.

                
4. One page max. Plain language, no jargon.

                
5. End with “Decisions needed” for leadership.

              

            

          

          
    
            
  1. 
              
    📁 weekly-status-report/
    
              
    📄 SKILL.md required
    
              
    📁 templates/ optional
    
            
    2. 
            
  2. ① The YAML headerBetween the --- lines: a name and a description. That's all it needs.
    3. 
            
  3. ② The description is the triggerThe AI reads only this until a task matches. Then it opens the rest.
    4. 
            
  4. ③ The playbookYour steps, format and rules, in plain English. No code needed.
    5. 
          

        

      

    


    
    

      

        
Works in both

        
One skill. ChatGPT and Claude.

        

          

            ChatGPT
            

              
Make one
Start a chat with “Build me a skill that…”, check it, then click Install.

              
Use it
Type @ and pick it, or let ChatGPT choose it when the task matches.

            

          

          

            📄 SKILL.md
          

          

            Claude
            

              
Make one
Ask Claude to build it, or upload one in Customize → Skills.

              
Use it
Claude loads it on its own when the task matches, or ask for it by name.

            

          

        

        
Why both? Skills follow an open standard, Agent Skills. Anthropic created it, and OpenAI, GitHub Copilot, Cursor and Gemini CLI use it too.

        
On work accounts, an admin may need to switch skills on first.

      

    


    
    

      

        
Why it matters at work

        
One team. One way of working.

        

          

            
Without a skill

            

              
              
              
              
            

            
Every manager's Friday report looks different.

          

          
📄 SKILL.mdshared with the team→

          

            
With a shared skill

            

              
              
              
              
            

            
Same format every time, even on a new hire's first day.

          

        

        
Other skills teams build
          💰 Finance: month-end close summary
          ⚖️ Legal: contract review notes
          🛠️ IT: incident write-up
          📣 Marketing: campaign brief
        

        
Pro Tip
Test it out of the box first. Before you build a skill, ask the AI to do the task without one. Today's models already handle much of what older skills had to spell out. Only package what it still gets wrong: your format, your rules, your company's know-how.

      

    


    

    
    

      

        

          
Idea 03 · Planning

          
See the plan
before the work.

          
For any big job, have the AI show you its plan first. Approve it, change it, or stop it.

        

        

          
Clean up our team's shared drive.

          

            
📋 My plan, before I touch anything:

            
    
              
  1. 1Sort files into one folder per project.
    2. 
              
  2. 2Delete Archive anything older than 2 years.
    3. 
              
  3. 3Rename files to one pattern.
    4. 
            

            
✓ Go ahead✎ Change it

          

          
Step 2: don't delete! Legal needs those. Archive them.

          
✓ Caught before a single file moved.

How to get the plan

        
Ask for the plan, anywhere.

        

          

            💬
            
Any chat

            
ChatGPT · Claude · Copilot · Gemini

            
“Before you start, show me your plan. Wait for my OK.”

            
          

          

            🛠️
            
AI coding tools

            
Claude Code · GitHub Copilot · Cursor

            
Press Shift+Tab until you see Plan. In Claude Code, you can also type /plan.

          

          

            🔎
            
Deep research

            
Gemini Deep Research

            
It writes its research plan first. Pick Edit plan or Start research.

          

        

      

    


    
    

      

        
Pro Tip For experienced users

        
“Plan mode is dead.”

        
📰 A former GitHub engineer's blog post, Sept 2026. 500+ comments on Hacker News. Even the creator of Claude Code agreed: today's models plan on their own.

        

          
It just changed jobs.

          
The AI doesn't need the plan anymore. You still do.

        

        
Pro Tip
          
Keep plan mode anyway. It's for you.

          
    
            
  • 🧭Understand what's about to happen
    • 
            
  • 🎛️Steer before anything changes
    • 
            
  • 🎓Learn how an expert would do it
    • 
          

          
Try: “You may not need a plan, but I do. Show me yours before you start.”
